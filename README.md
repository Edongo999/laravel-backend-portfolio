# Laravel Backend - Portfolio

## 🇫🇷 Version Française

Ce projet est un backend développé avec **Laravel 12.9.2**, connecté à une base de données **Supabase (PostgreSQL)**.  
Il fournit une API sécurisée pour gérer **mes articles, mes notifications et mon profil**, avec authentification via **Laravel Sanctum**.  

Ce backend est conçu comme un **dashboard personnel** : je suis le seul administrateur qui gère et publie le contenu de mon portfolio en ligne.

---

### 🚀 Technologies
- Laravel 12.9.2
- Supabase (PostgreSQL)
- Sanctum pour l’authentification
- Render pour le déploiement
- React (frontend)

---

### 🎯 Fonctionnalités
- Authentification sécurisée (Sanctum)  
- Gestion et publication des articles  
- Administration de mon profil utilisateur  
- Notifications en base  

---

### 🛠️ Compétences mises en avant
- Développement backend avec Laravel  
- Intégration API REST sécurisée  
- Authentification avec Sanctum  
- Déploiement cloud (Render, Vercel)  
- Base de données PostgreSQL (Supabase)  

---

### 🌐 Déploiement
- Backend : Render  
- Base de données : Supabase  
- Frontend : Vercel
