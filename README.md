# Laravel Backend - Portfolio

Ce projet est un backend développé avec **Laravel 12.9.2**, connecté à une base de données **Supabase (PostgreSQL)**.  
Il fournit une API sécurisée pour gérer les utilisateurs, les articles et les notifications, avec authentification via **Laravel Sanctum**.

## 🚀 Technologies
- Laravel 12.9.2
- Supabase (PostgreSQL)
- Sanctum pour l’authentification
- Render pour le déploiement
- React (frontend)

## 🎯 Fonctionnalités
- Authentification sécurisée (Sanctum)
- Gestion des utilisateurs
- CRUD des articles
- Notifications en base

## 🛠️ Compétences mises en avant
- Développement backend avec Laravel
- Intégration API REST sécurisée
- Authentification avec Sanctum
- Déploiement cloud (Render, Vercel)
- Base de données PostgreSQL (Supabase)

## 🌐 Déploiement
- Backend : Render  
- Base de données : Supabase  
- Frontend : Vercel
